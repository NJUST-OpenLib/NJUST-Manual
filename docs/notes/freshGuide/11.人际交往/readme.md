# 人际交往

进入大学，意味着进入一个与高中截然不同的社交环境。高中时期，同学们大多来自同一城市，生活背景相似，目标高度一致；而大学的班级由来自五湖四海的同学组成，每个人都有不同的成长经历、家庭背景、生活习惯和价值观念。

这种变化带来了自由与挑战。自由在于，你可以选择与谁交往、如何交往；挑战在于，没有人有义务主动迎合你，关系不会自动建立，差异不会自然消失。

大学的人际关系需要时间培育。尊重差异比寻找相同更重要，真诚比技巧更可靠。以下各章将帮助你建立一种健康、成熟的交往观念。
