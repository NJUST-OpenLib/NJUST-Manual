从教务系统导出成绩单，你会看到一张很长的表。表上有非常多的信息。这对所有同学来说都是新事物。需要慢慢学习。

绩点怎么算、什么是学位绩点，见[学分与绩点](./1.学分与绩点.md)。

## 一、先分清两个不同的维度

成绩单上最容易被混在一起的就是"课程性质"和"课程属性"。它们回答的是两个不同的问题：

- **课程性质** → 这门课在培养方案里处于哪一层（公共基础？学科平台？专业核心？）
- **课程属性** → 你对这门课有多少选择权（必须修？还是自己挑？）

两者是交叉的。比如"通用英语"是**必修**的**学科教育课**，"先进传感技术"是**任选**的**专业选修课**。看成绩单时要两列一起看。

## 二、课程性质：这门课属于哪一层

以智能电网信息工程专业为例：

| 课程性质 | 是什么 | 典型课程 |
| --- | --- | --- | 
| **通识教育课** | 全校统一的公共基础，不分专业 | 思政系列、形势与政策、体育、军事理论、劳动教育、就业指导、大学物理、概率统计、工程数学 | 
| **学科教育课** | 按学科大类打底的平台课，同一大类的专业都要修 | 高等数学、线性代数、C 语言、数据结构、大学计算机、工程制图、电路、模电、数电、通用英语、各类综合实验 | 
| **专业教育课** | 你这个专业的核心课，换专业就全变了 | 电机学、电力系统分析、继电保护、微机原理、毕业实习、毕业设计 | 
| **通识教育选修课** | 全校范围任选的素质课，按类别管理 | 人文素养类、艺术审美类、经济社会类（含四史）、自然科技类 | 
| **专业选修课**| 本专业内的方向性选修，按类别管理，合计分数足够即可 | 先进传感技术、电力系统计算机辅助分析、优化方法等 |
| ...| ... || 


::: warning 每一类的学分要求是分开算的
培养方案会**分别**规定这几类各需多少学分，**不能互相顶替**。专业选修多修 4 学分，抵不了通识选修缺的 2 学分——总学分够了照样毕不了业。

这是每年都有人踩的坑，建议大二起每学期核对一次。
:::

## 三、课程属性：你有多少选择权

| 课程属性 | 含义 | 
| --- | --- | --- |
| **必修** | 必须修、必须通过。挂了要补考或重修 |
| **限选** | 在指定的一小组课里按要求选够门数或学分 |
| **任选** | 自己挑课，但每个类别有最低学分线 | 

三点说明：

**必修占了绝大多数。** 大学的"自由选课"没有想象中那么自由——本科四年八成以上的学分是定死的，真正由你决定的只有 20 学分左右。

**"限选"通常出现在外语** 如您在大一上学期期末考试位居前列，下学期的通用英语就可以只选一门，否则要选二门。

**"任选"不等于"可以不选"。** 它只是让你自由挑课，学分要求照样是硬的。每年都有人大四才发现通识选修还差两个学分。

## 四、通识教育选修课的类别

通识选修课还会区分类别，例如：

| 类别 | 课程举例 |
| --- | --- |
| 人文素养类 | 大学生心理健康教育指导、关爱生命——急救与自救技能、文化遗产与自然遗产 |
| 艺术审美类 | 西方建筑艺术赏萃、中外园林美学对比研究、百年奥斯卡经典电影赏析、文物精品与中华文明 |
| 经济社会类（含**四史**） | 新青年·习党史、改革开放史、药事法规 |
| 自然科技类 | 火灾科学导论 |

培养方案通常要求**每个类别至少修够一定学分**，其中"四史"类常有单独的硬性要求。也就是说，你不能十几个学分全选艺术类。
可以使用[南理工教务增强助手](https://enhance.njust.wiki)查看选修课课程对应的类别。

## 五、考核方式：考试与考查

| 考核方式 | 怎么给分 |
| --- | --- |
| **考试** | 期末统一命题闭卷或开卷，成绩多为百分制 |
| **考查** | 靠平时表现、实验报告、作品、论文等过程性材料 |

**"考查"不等于"水课"。** 样本里学分最高的一门课是 **10 学分的毕业设计**，它就是考查课；各类综合实验、工程实践、科研训练也都是考查课，占了总学分的四分之一以上。

这类课没有期末一张卷子给你翻盘的机会，分数是整个学期一点点攒出来的。报告写得糊弄、实验缺席，最后就是一个不好看的等级。

## 六、一门课的分数是怎么算出来的

高中的成绩基本等于考试成绩。大学不是——**成绩单上那个数字，是"平时成绩"和"期末成绩"按比例加权出来的**，通常叫总评成绩。

```
总评成绩 = 平时成绩 × 平时占比 + 期末成绩 × 期末占比
```

比例由课程的教学大纲规定，不同课程不一样，**常见的是三七或四六**（平时 30% + 期末 70%，或平时 40% + 期末 60%）。实践性强的课，平时占比可能更高。

::: tip 第一节课要记下三件事
比例不是秘密，任课老师通常在第一节课就会讲，课程大纲里也写着：

1. 平时分和期末分各占多少；
2. 平时分由哪些部分构成；
3. 缺勤、迟交作业分别怎么扣。

这三个数字决定了你这学期该在这门课上怎么用力。开学第一周记进备忘录，比期末找同学打听靠谱得多。
:::

### 平时成绩通常包含什么

- **出勤与课堂表现**：点名、提问、随堂练习。这部分基本"只要来就有"。
- **作业**：书面作业、编程作业、习题册。
- **小测与期中考试**：不少课把期中考试算进平时分。
- **实验报告**：理工科课程里占比很高。
- **分组作业与课堂汇报**：需要协作的部分，别做搭便车的那个人。

上一节说的**考查课没有期末统一考试，整门课的成绩全部由这些过程性材料构成**——相当于平时占比 100%。

### 为什么平时分比你想的重要

因为绩点是**跳变**的（见[学分与绩点](./1.学分与绩点.md)），平时分往往决定你落在哪一档。

以平时 40% + 期末 60% 为例，同一份期末卷子都考 70 分：

| 平时成绩 | 总评成绩 | 绩点 |
| --- | --- | --- |
| 100 | 40 + 42 = **82** | 3.3 |
| 85 | 34 + 42 = **76** | 2.7 |
| 70 | 28 + 42 = **70** | 2.0 |

期末分数一模一样，绩点从 2.0 到 3.3，差了 1.3。而平时分和期末考试有个本质区别：**它不靠临场状态，只靠按时出现、按时交东西。** 这是整个成绩体系里最容易拿、也最容易白丢的部分。

反过来说，平时分也是安全垫。期末考砸的时候，一个扎实的平时分往往就是"及格"和"挂科"之间的那几分。

::: warning 卷面成绩可能另有门槛
有的课程会额外规定"卷面成绩低于某个分数即不及格"，即使加权后的总评超过 60 分。这类规则写在课程大纲或考核方案里，**以任课老师和课程大纲的说明为准**，不要指望平时分能完全兜底。
:::

## 七、为什么有的成绩是数字，有的是"良+"

样本里有 15 门课、27 学分记的不是分数，而是 **优 / 优− / 良+ / 良 / 良− / 中 …** 这样的等级。这些几乎都是考查课。

等级成绩同样要折算成绩点。按[学分与绩点](./1.学分与绩点.md)一文中规定的等级列（A / A− / B+ / B / B− / C+ / C / C− / D / F）对应过来：

| 等级成绩 | 对应等级 | 绩点 | 大致相当于百分制 |
| --- | --- | --- | --- |
| 优 | A | 4.0 | 90 分及以上 |
| 优− | A− | 3.7 | 85 ~ 89.5 |
| 良+ | B+ | 3.3 | 82 ~ 84.5 |
| 良 | B | 3.0 | 78 ~ 81.5 |
| 良− | B− | 2.7 | 75 ~ 77.5 |
| 中+ | C+ | 2.3 | 72 ~ 74.5 |
| 中 | C | 2.0 | 68 ~ 71.5 |
| 中− | C− | 1.5 | 64 ~ 67.5 |
| 及格 | D | 1.0 | 60 ~ 63.5 |
| 不及格 | F | 0 | 60 分以下 |

::: warning 这张对应表是推得的，不是规定原文
学校规定里给出的是"百分制成绩—成绩等级（A/B/C…）—绩点"三列，成绩单上显示的是"优/良/中"。上表按两者的等级顺序对应，**具体折算结果请以教务系统显示的绩点为准**。
:::

真正要留意的是它的权重。**一门 10 学分的毕业设计，拿"优"和拿"良"相差 1.0 绩点，乘上 10 学分就是 10 个学分绩点**——这个差距比你在任何一门 2 学分的课上努力都更能改变最终绩点。考查课值得认真对待，原因就在这里。

## 八、学时

成绩单上还有一列"总学时"。它和学分的比例在不同类型的课里差别很大：

| 课程类型 | 举例 | 学时 / 学分 |
| --- | --- | --- |
| 普通讲授课 | 工程制图 32 学时 / 2 学分、C 语言 64 / 4、高等数学（Ⅱ）96 / 6 | 约 **16 学时 = 1 学分** |
| 实验与实践课 | 工程实践 80 / 2、军事训练 96 / 2、电路综合实验 40 / 1 | **40 ~ 48 学时 = 1 学分** |
| 毕业设计 | 560 学时 / 10 学分 | **56 学时 = 1 学分** |

结论很实用：**看这学期忙不忙，要看学时；看能不能毕业和绩点高不高，要看学分。** 实验和实践课占用的时间远多于它们给的学分，排课时要给它们留出真实的时间预算，不要按学分数去估计工作量。

另外别忽略那些零点几学分的课。样本里"形势与政策"分八个学期修完，每学期只有 0.2 ~ 0.3 学分，加起来也不到 2 学分——但它是**必修**，漏掉任何一学期都得补。这类小课门数多、学分低、最容易忘。

## 九、成绩单上看不出来的两件事

第一，哪些课是"学位课程"。成绩单没有这一列，但正是它决定你的学位绩点——也就是保研、评奖、授学位真正看的那个数字。

这里有个反直觉的例子：样本里的**通用英语是"必修 + 学科教育课"，4 学分，但它不计入学位绩点**。所以**不要用课程性质去猜学位课程**，两者是独立的两套划分。学位课程清单只能在你自己的培养方案里查。

第二，四六级折算的 8 学分。它不出现在这张课表里，但会计入绩点。折算方法见[学分与绩点](./1.学分与绩点.md)。

还有一列平时是空的、但值得知道它存在：**成绩标识**。补考、重修等情况会在这一列做标记，它可能影响评奖评优资格的审核。补考和重修的流程见[分数、补考与重修](./3.分数、补考与重修.md)。
