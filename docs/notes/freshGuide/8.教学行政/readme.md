# 教学行政

大学和高中最大的制度差异，是你从"被安排"变成了学分制下的自主管理者：课自己选、成绩自己负责、毕业要求自己盯。这一部分整理与教务、学籍、成绩相关的规则。

这些规则看着枯燥，但它们直接决定你能不能保研、能不能评奖、能不能顺利毕业。开学第一个月抽时间读一遍，比大三再来补课划算得多。
