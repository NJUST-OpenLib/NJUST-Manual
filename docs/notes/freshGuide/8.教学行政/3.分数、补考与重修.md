大学不是高中。

## 一、分数

课程的考核方式分两种

- **考试课**：期末一张卷子（开卷或闭卷），记考试成绩。
- **考查课**：没有统一考卷，以考查的形式判断学习情况，学生一般要在期末提交一份报告、论文、程序、实物或者个人作品。
  
两类课的成绩都不是单一来源，而是按课程大纲规定的比例加权：

```
课程成绩 = 平时分 × 平时分比例 + 期末考核分 × 期末考核分比例 + 过程性考核 × 过程性考核比例
```

百分制课程必须取得 60 分（含）以上，才能修得这门课对应的学分。在学分上，59 分和 0 分是一回事，都没有。等级制课程的"及格"对应 60 ~ 63.5 分，对照表见[学分与绩点](./1.学分与绩点.md)。

::: warning 总评过线也可能不及格
有的课程另外规定"卷面成绩低于某个分数即不及格"，俗称斩杀线。不要指望平时分能完全兜底。
:::

## 二、没过

| 课程类型 | 没通过怎么办 |
| --- | --- |
| 通识教育选修课**以外**的课程（必修、限选、专业选修等） | 先补考；补考不过再重修。对于没有安排补考的课程，有一次免费重修机会 |
| **通识教育选修课** | 一般不安排补考和重修，需要另选一门同类别的课，把这一类的学分补够 |
 
::: tip 通识选修挂了，缺的是学分不是绩点
通识选修课的分数不会影响你的平均学位学分绩点，因此通识选修课考 0 分也不会拉低你的绩点。只会导致你有一个挂科记录，并且需要再选修该类别课程。
:::

假设大一上学期考了一门《高等数学 I》，你担心自己没考过，接下来大致是这个顺序：

1. 期末考完，成绩陆续录进教务系统，自己去查。发现成绩为 51 分。
2. 寒假：复习要自己安排，多刷历年题。
3. 开学前：参加补考。
4. 补考过了 → 拿到学分，这件事结束（成绩单上会留标记，见第五节）。
5. 补考没过，或这门课本来就没安排补考 → 报名重修班，和其他同学一起重新学习这门课程。

## 三、补考

**时间：每学期开学前。** 学校会对上一年度课程成绩不及格的学生组织补考。具体科目、场次和名单以教务处和学院的通知为准。关注年级群和教务处网站（https://jwc.njust.edu.cn) 。

难度：补考考卷一般与期末考卷相当。

**不是每门课都有补考。** 补考的形式是一张卷子，所以它主要针对考试课；实验、实践、毕业设计这类考查课一般无法补考。对于没有安排补考的课程，学校会有一次免费重修机会（具体请咨询教务处）

补考通过依然会计入挂科，只是不必重修。

根据 2024 年新规定，补考的分数组成与初次考试一样，但最高分数为 75 分（？）。

## 四、重修

若学生既没有通过相关课程的考试，也没有通过补考，为了取得这门课对应的学分，就需要重修该门课程。重修的意思就是你再重新上一遍这门课：跟着开课班把课听完、作业交完、期末考完，成绩重新算一遍。

要自己进行重修选课。重修不会自动给你安排，得在教务系统规定的时间里选。重修选课可以安排在任意学期，但必须在毕业之前修完。建议尽早完成。

重修课可能和本学期课表冲突。重修课的时间按开课班排，不会为你避开本学期的课程。冲突课程可以选择间听

::: tip 什么是间听？

间听，顾名思义，就是在本学期课表上空出时间，在重修班上间歇听课。间听适用于课程存在冲突而无法安排的情况（如重修、转专业、提前修读等）。
间听要求课程的冲突时间占比必须在 0~50% 之间。当课程冲突需要重修时，选课页面会有提醒。需要申请后等待任课老师审批通过。

:::

重修课程没有补考机会。

## 五、影响

挂科会导致必修课和学位课程以 0 绩点和原始学分计入。

一门 4 学分的学位课挂科，相当于往学位绩点里塞进一个 4 学分的 0 绩点，这是对绩点伤害最大的一种情况，远比某门课考了 70 分严重。算法见[学分与绩点](./1.学分与绩点.md)。

成绩单：打印成绩单时会在课程后面添加一个微小的记号，用以说明重修或补考。   
需要注意的是，您随时可以在`微信企业号 - 自助打印中`打印成绩单，该成绩单不带重修标记，但只有电子印章。

**保研与评奖：有影响，但容错空间不是零。** 
挂科确实会影评优和奖学金，因此我们应该尽可能避免低分科，更要尽可能避免挂科。   
这是大家都知道的道理，但我更想说，万一挂科了怎么办？   
大学的意义并非在于考试考出好成绩，大学的意义在于为你提供一个自由发展的平台。拥有一个好成绩会让你未来更舒服一些，但如果你认为大学的目标就只是考出好成绩，或者认为没有好成绩你就完蛋了，那你的人生才是完蛋的。
我希望所有新生都尽快转变这个思路，不要把大学当做高中看待。

而你的辅导员，绝大多数都是当年的好学生、是典型的做题家，几乎没有怎么接触过社会，没有接触过招聘，本科毕业保研本校，毕业后留校工作，可能一辈子都在高校里面渡过。
因此，他们一般会在四年内不停的灌输”挂科就完蛋了“，你的保研作废，你的评优作废，你的奖学金作废，你的人生作废，你这辈子完蛋了。
事实上并非如此，这只是你辅导员的人生轨迹。你的辅导员如果本科挂科，就不能评优，不评优就难保研，难保研就难入校工作，难入校工作他就不会是这个辅导员了。
因此你的辅导员说如果挂科了你的大学就完了，实际上是”如果你挂科了，你就不能走他来过的路了“

我希望大家意识到这一点，你未必要成为你的辅导员，你也不必成为任何人。任何人的经历都只可以用来参考，做好自己就可以了。

你的大学有很多事情可以做，你可以出去旅游，踏遍祖国大好河山、去吃饭、去做短视频、去谈对象、去看书、去摄影、去 coding、去竞赛、去交友、去培养兴趣爱好、去考研、去考公、去应聘好企业...你的人生选择非常多。
南理工有非常多的毕业去向非常好的学长学姐都有过挂科记录。依然可以进入央企、大厂或是高水平院校。

同时南理工也有非常多的学长学姐凭借能保研外校的实力、非常高的绩点、非常多的奖项保研本校（hehe），最终去向满意的岗位。

大学里面变数非常多，任何一个事件都会改变你的人生轨迹，但什么都不会导致你人生彻底完蛋。

因此，若您已经挂了一科，您不必自暴自弃，放平心态继续学习，考试前多做题就好。

但需要说明的是，2025 级以后，有不超过一门课程挂科记录的学生依然可以获得推免资格。以当年学院的推免实施细则为准。

## 六、麻烦

**缺考。**  缺考没有补考资格。

**违纪** 作弊轻则成绩作废，重则取消学位证；具体的认定和处理办法以《学生手册》为准。请诚信考试。

**连续多门挂科。** 累计未通过的学分数达到一定程度会触发学业警示，再往后会影响毕业和学籍。

## 七、建议

1. **开学第一节课就记下分数构成和考核方式。** 比例、构成、缺勤和迟交怎么扣，这三件事决定你在这门课上该怎么用力、怎么翘课。
2. **查到不及格，先确认不是记录问题。** 如果有充分理由认为成绩有误，先找任课老师，再找学院教务。
3. **假期就开始准备补考**，别等开学前三天。
4. **挂科之后心态怎么调整**，挂科必须要重视，但它不是世界末日。如果你把挂科当成世界末日，那才是真的世界末日
