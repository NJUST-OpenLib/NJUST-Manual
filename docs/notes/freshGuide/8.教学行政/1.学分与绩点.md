高中的成绩单上只有分数和排名。大学的成绩单上会多出两列：**学分**和**绩点**。

这决定你能否毕业、保研、评奖。

::: tip 基础概念
1. **学分**说的是这门课有多"重"。修够培养方案要求的学分才能毕业，和你考多少分无关。
2. **绩点**说的是这门课你学得多好。60 分以下为 0，60 分对应 1.0，90 分及以上都是 4.0。
3. **平时大家说的"绩点"，指的是「学位绩点」**——只用培养方案里的**学位课程**算出来的那个平均值。通用英语、选修课**不算**在里面，四六级折算的 8 学分**算**在里面。

:::

::: warning 本文依据
绩点对应关系与计算公式引自[《南京理工大学本科学生管理规定（修订）》](https://xgc.njust.edu.cn/d9/ce/c4861a121294/page.htm)第二十二条。具体培养方案、课程学分和认定细则各年级、各学院可能不同，**遇到影响切身利益的情况请以教务处和本院教务办的答复为准**。
:::

## 学分

学分是课程的"重量单位"，与课程的课时量挂钩。课上得越多、周期越长的课，学分越高。高等数学这类一学期几十个课时的课通常有 5、6 学分，而一门考查性质的选修课可能只有 1 学分。

关于学分，有三件事需要先建立概念：

**学分只关心"过没过"，不关心"考多好"。** 同一门 4 学分的课，你考 60 分和考 99 分，拿到的都是 4 学分。分数的差异体现在绩点上，不体现在学分上。

**毕业的硬门槛是学分。** 你的培养方案规定了毕业所需的总学分，以及各类课程（必修、专业选修、通识选修、实践环节等）分别需要多少学分。**任何一类没修够，都不能毕业**——总学分够了但通识选修差 2 学分，同样毕不了业。这是每年都有人踩的坑，建议大二起每学期核对一次培养方案。

**学分只能通过修课获得。** 考驾照、考证书、参加社会实践都不折算学分，唯一途径是修完对应课程或实验。相关问题见[常见问题汇总](/notes/freshGuide/FAQ.html)。

## 绩点

我校用的是等级制对照表：

| 百分制成绩 | 成绩等级 | 绩点 |
| --- | --- | --- |
| 90 ~ 100 | A（优秀） | 4.0 |
| 85 ~ 89.5 | A− | 3.7 |
| 82 ~ 84.5 | B+ | 3.3 |
| 78 ~ 81.5 | B（良好） | 3.0 |
| 75 ~ 77.5 | B− | 2.7 |
| 72 ~ 74.5 | C+ | 2.3 |
| 68 ~ 71.5 | C（中等） | 2.0 |
| 64 ~ 67.5 | C− | 1.5 |
| 60 ~ 63.5 | D（及格） | 1.0 |
| < 60 | F（不及格） | 0 |

这张表有两个特点值得注意。

**它不是线性的，档与档之间是跳变的。** 77 分和 78 分只差 1 分，绩点却差了 0.3（2.7 → 3.0）；而 78 分和 81 分差了 3 分，绩点完全一样。这意味着**分数落在档位边缘时，1 分的价值远高于平时的 1 分**。如果你的成绩是 84 分或 89 分，为一次平时作业多花半小时是很值的。

**满绩是 4.0，且 90 分以上不再增加。** 考 90 和考 100 的绩点相同。把时间从一门已经稳过 90 的课，挪到一门可能只有 77 分的课上，对平均绩点的提升要大得多。

## 计算


**第一步：查表，得到每门课的单科绩点。** 就是上面那张表。

**第二步：乘上学分，得到这门课的「学分绩点」。** 5 学分的课考 3.3，产出是 16.5；1 学分的课考 4.0，产出只有 4.0。学分越高的课，说话越管用。

```
学分绩点 = 该课程学分 × 该课程单科绩点
```

**第三步：求加权平均。** 把学分绩点加起来，除以学分加起来。

```
                 Σ（各课程学分 × 各课程单科绩点）
平均值 = ────────────────────────────────────
                      Σ（各课程学分）
```

到这里出现了本文唯一容易绕晕的地方：**第三步里"把哪些课放进来"，决定了你算出的是哪个数字。** 学校同时统计两个口径：

| 平时怎么叫 | 学校的正式名称 | 算哪些课 | 拿去干什么 |
| --- | --- | --- | --- |
| **学位绩点**（也就是大家口中的"绩点"） | 学位课程平均学分绩点 | **只算培养方案指定的学位课程** | 保研、评奖评优、学位授予、排名 |
| 总绩点 | 平均学分绩点 | 已修的全部必修课 + 已通过的选修课 | 学校衡量总体学习质量的指标 |

::: tip 只需要记住"学位绩点"
你在班级群里、保研群里、辅导员口中听到的"绩点 3.5""绩点排名前 10%"，说的都是**学位绩点**。所以：

- **通用英语、通识选修**这类课，考得再高也不会计入；
- **四六级折算的 8 学分**会计入这个数字（；
- 到底哪几门课算学位课程，**只能看你自己的培养方案**（一般来说除了通识选修课和英语，都会算入其中）


:::

### 例子

假设某学期修了五门课，其中前三门是培养方案里的学位课程：

| 课程 | 是否学位课程 | 学分 | 成绩 | 单科绩点 | 学分绩点 |
| --- | --- | --- | --- | --- | --- |
| 高等数学 | ✅ 是 | 5 | 83 | 3.3 | 16.5 |
| 大学物理 | ✅ 是 | 4 | 76 | 2.7 | 10.8 |
| 程序设计 | ✅ 是 | 3 | 91 | 4.0 | 12.0 |
| 通用英语 | ❌ 否 | 3 | 88 | 3.7 | 11.1 |
| 通识选修 | ❌ 否 | 2 | 95 | 4.0 | 8.0 |

**学位绩点**（只算前三门）：

```
(16.5 + 10.8 + 12.0) ÷ (5 + 4 + 3) = 39.3 ÷ 12 ≈ 3.28
```

**总绩点**（五门全算）：

```
(16.5 + 10.8 + 12.0 + 11.1 + 8.0) ÷ (5 + 4 + 3 + 3 + 2) = 58.4 ÷ 17 ≈ 3.44
```

同一个学期，两个数字差了 0.16。从这个例子能看出两件很实际的事：

**选修课刷高分，对你的排名没有帮助。** 那门 95 分的通识选修把总绩点拉高了，但学位绩点一动不动。每年都有同学疑惑"我选修课全是 95 分，为什么绩点排名还这么低"，答案就在这里。

**学位课程里的高学分低分，杀伤力是成倍的。** 大学物理 76 分看着不算低，但它 4 学分、绩点只有 2.7，是这个学期学位绩点的主要拖累。这就是为什么高数、物理、专业核心课值得优先投入时间。

## 挂科

学校规定里有一个措辞差异，很容易被忽略：

> **已修**必修课程与**已通过**的选修课程的学分绩点之和，除以上述课程的学分总数。
>
> **已修**学位课程的学分绩点之和，除以上述课程的学分总数。

- 必修课和学位课程用的是"**已修**"。修了就算，**包括没通过的**。挂科会以 0 绩点、按其学分权重算进你的平均值里。
- 选修课用的是"**已通过**"。没通过的选修课不计入（但学分仍然缺着，得补回来）。

因此，要极力避免高学分课程挂科。其权重太大。


## 四六级

这是新生问得最多的一条。

四六级成绩会被折算成课程成绩计入绩点，**这部分共 8 学分，且计入学位绩点**
换句话说，它是少数几件"能直接影响你排名"的校外考试。折算方式是先把卷面分按比例折算成百分制，再按第二节的表查绩点：

```
折算百分制成绩 = 四六级分数中最高者 ÷ 710 × 100
```

常见分数的可能对应结果：

| 四六级分数 | 折算成绩 | 绩点 |
| --- | --- | --- |
| 425（合格线） |  60 | 1.0 |
| 460 | 64.8 | 1.5 |
| 500 | 70.4 | 2.0 |
| 540 | 76.1 | 2.7 |
| 570 | 80.3 | 3.0 |
| 590 | 83.1 | 3.3 |
| 610 | 85.9 | 3.7 |
| **639** | **90.0** | **4.0（满绩）** |
| 710（满分） | 100 | 4.0 |

四六级占 8 学分，权重相当高，较低的成绩会让您的绩点受到较大影响。   
需要注意的是，它是唯一可以反复重考的绩点。四六级每年两次、可以一直刷到毕业前。这大概是你四年里性价比最高的一次绩点投资。（保研名额只看第一次成绩，但成绩单显示最高分，因此出国可以重修刷分）   
关于四六级的报名资格选拔，见[开学考试](/notes/freshGuide/summerPrep/freshmanExam.html)。   


## 影响

| 事项 | 主要看 |
| --- | --- |
| 能否毕业 | **学分**（各类别都要分别修够） |
| 能否拿到学士学位 | **学位绩点**，满足培养方案且＞2.0 即可 |
| 保研（推免） | **学位绩点**，通常还结合综测排名，按各学院标准 |
| 奖学金、评优评先 | **学位绩点** + 综测 |
| 出国申请 | 成绩单显示的一般是总绩点 |
| 学业警示、退学预警 | 累计未通过的学分数 |

需要说清楚的是：绩点重要，但它不是大学的全部。竞赛、科研、实习、社会实践都是您的选择。
成绩不理想不等于四年白费。

## 建议

1. 开学第一个月，把培养方案读一遍。这份清单决定了你的时间该往哪投。花两小时，能省掉后面四年的反复焦虑。
2. 优先保住高学分的学位课程。5 学分的高数考 78 分，比 1 学分的选修课考 95 分有用得多；后者对学位绩点的贡献是零。
3. 别在选修课上过度用力。选修课的作用是修够学分、别挂科。把省下来的时间放到学位课程上。
4. 四六级尽早考，一大二时间相对宽裕，而且它可以反复刷分。(保研对四六级分数有要求，参见推免规则)
5. 涉及补考、重修、绩点认定、学位课程范围的问题，咨询本学院教务。
