# 高中大学衔接指南

从高中到大学，不仅是一次升学，更是一个人从"被安排"走向"自己决定"的转变。这本指南想传授的并非高深学问，而是那些在课堂与家庭中被忽视的"常识"——如何照顾自己、如何与人相处、如何甄别信息、如何维护自己的权益。

它写给每一个即将或刚刚踏入大学校园的你，也写给那些愿意放手、让孩子真正长大的家长。
