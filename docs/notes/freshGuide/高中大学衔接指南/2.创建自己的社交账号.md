进入大学后，班级通知在群里发布，课程资料通过群文件传递，社团招新需要扫码入群，辅导员找你可能是一条微信。拥有一个属于自己、且能正常使用的社交账号，已经是参与大学生活的基本条件。

不少同学在高考结束前，手机的使用受到家庭严格管理，有些人直到填报志愿时才拿到第一部属于自己的手机。如果你目前还没有自己的账号，这并不奇怪，也不落后于任何人。从现在开始建立就好。

::: tip 本章的分工
本章讲的是**如何把账号本身建好**：需要哪些基础设施、资料怎么填、隐私和安全如何设置。

至于建好之后**怎么与人相处**。群里怎么说话、匿名平台的底线、二手交易的分寸——请参阅[网络社交篇](../11.人际交往/5.网络社交篇.md)。
:::

## 先解决两项基础设施

社交账号并非孤立存在，它挂在两样东西上。这两样没准备好，后面所有麻烦都由此而来。

**一个登记在自己名下的手机号。** 这是你全部数字身份的根：账号注册与找回、短信验证码、银行卡、学信网、教务系统，最终都指向它。

- 尽量使用实名登记在你本人名下的号码，而不是父母名下的副卡。日后办理银行卡、申请学籍相关业务、找回账号时，"号码不在本人名下"会带来许多不必要的周折。
- 不要用父母的手机号注册属于你自己的账号。验证码会发到父母手机上，将来更换号码、解绑、找回密码都要反复麻烦对方，而账号里的社交关系本该由你自己掌握。
- 这个号码请尽量长期保留。学校平台、教务系统、各类平台都绑定着它，频繁更换号码是自找麻烦。
- 关于校园网与运营商套餐的选择，详见[网络通信](/notes/freshGuide/networkCommunication)。

**一个体面且长期可用的邮箱。** 邮箱的使用频率不如聊天软件，但重要性更高：账号注册、教务通知、竞赛报名、投稿、实习与求职，都要经过它。

- 邮箱地址本身会出现在简历、论文和邮件签名里。建议使用姓名拼音、或姓名拼音加数字这类中性的组合，避免使用带昵称、表白对象、非主流字符的地址——它会跟着你很多年，出现在你不希望它出现的场合。
- 入学后学校会分配校园邮箱（学号@njust.edu.cn)，用于订阅学术数据库、申请学生优惠、接收官方通知，届时记得激活。但个人邮箱仍需保留：校园邮箱会在毕业后停用。
- 邮箱是钓鱼诈骗的主要入口之一，相关识别方法见[防骗指南](/notes/freshGuide/antiScam.html)。

## 微信与 QQ：在大学里的不同分工

在国内高校，这两个软件承担着不同职能，通常两个都需要：

| | 主要用途 |
| --- | --- |
| **QQ** | 班级群、课程群、社团群、老乡群。群文件、群相册、群公告的功能更强，聊天记录便于沉淀查阅，是课程资料流转的主要渠道 |
| **微信** | 与辅导员、任课老师、行政部门、实习单位的联系；日常支付；同学之间的私下沟通 |

一个常见的误区是"我只用其中一个就够了"。实际情况是：你会因为没有 QQ 而拿不到课程资料，也会因为没有微信而联系不上老师。

两个账号都请完成实名认证，绑定手机号与邮箱。

## 把资料填成"别人能认出你"的样子

头像与昵称的基本原则在[网络社交篇](../11.人际交往/5.网络社交篇.md)中已有说明，这里补充几点具体做法：

1. **进群后第一件事是改群昵称。** 班级群、课程群建议改为"姓名"或"学号 + 姓名"。老师点名、班委统计、组队分工都靠它，一个叫"栀子花开ღ"的成员会让所有人都不知道该找谁。当然，您的昵称没有必要改为实名，修改群内的昵称即可。
2. **保持头像与昵称的稳定。** 频繁更换会让别人反复确认"你是谁"。
3. **默认头像与默认 ID 是有代价的。** 在班级群和课程群里，它们容易被管理员误认为广告账号而清退。
4. **想一想这个界面会被谁看到。** 未来向老师请教问题、请导师签字、联系实习单位、加面试官好友时，对方看到的就是这个头像、这个昵称、这条个性签名。不需要刻意包装，但也不必给自己制造额外的解释成本。请不要使用低俗内容。

## 隐私设置：花十分钟，省很多事

注册完成后，请立刻花十分钟完成下面这些设置。它们只需要做一次，却能挡掉日后大量的麻烦：

- **通过手机号搜索到我"。** 这一项请自行决定是否关闭或者开启。
- **收紧空间与朋友圈的可见范围**，并顺手清理一下高中时期不希望被现在的同学看到的内容。
- **不要在公开资料里填写这些信息**：宿舍楼号与房间号、身份证号、完整出生日期、家庭住址、家长手机号。这些是"猜密码"和"冒充你"最常用的原料。
- **发图前检查背景。** 快递面单、学生卡、火车票、门牌号、宿舍窗外的标志物，都可能出现在你不在意的画面角落里。快递单上的姓名、电话和地址尤其需要遮挡。
- **谨慎使用共享实时位置**，用完及时关闭。
- **不要在公开平台留手机号**，包括发失物招领时——这会给你带来大量骚扰电话。

## 账号安全

账号被盗不只是"少了个号"。你的账号会被用来向你的同学、家人借钱、发布诈骗信息，你的社交关系会成为别人行骗的工具。

- **不同平台使用不同密码。** 一处泄露就全线失守，这是最常见的被盗原因。用"姓名拼音 + 生日"这类组合等于没有密码。记不住可以用密码管理器，或者至少保证邮箱、聊天软件、网银这三类的密码互不相同。
- **开启二次验证、登录设备锁、账号保护**等功能，并绑定好手机与邮箱作为找回渠道。
- **短信验证码不给任何人，包括"熟人"。** 对方自称辅导员、学长、客服、同学，都不例外——盗号者最常做的事就是用你被盗的账号去骗你的朋友。
- **不出借、不出租账号，也不要出租手机卡和银行卡。** 账号被用于刷单、诈骗、洗钱时，责任会追到你本人。
- **在公共电脑上用完就退出登录。** 机房、打印店、图书馆的电脑不要勾选"记住密码"和自动登录。
- **发现被盗立刻做三件事**：修改密码、通知常用的几个群和好友"我的号被盗了，任何借钱信息都不是我"、通过官方渠道申诉冻结。

## 加谁、进哪个群

- **官方群的入口必须来自官方渠道**：录取材料、学院或辅导员的正式通知、学校官网与官方公众号。群里有人发"这是官方新群，请大家扫码加入，否则无法入学"，先去官方渠道核实。每年开学都有人靠这一招把新生骗进假群。
- **陌生人加好友，先问来意再决定。** 说不清自己是谁、为什么加你的，可以不通过。
- **群里涉及金钱的通知一律核实。** "交资料费""交班费""补缴材料费"之类的消息，正确做法是去官方渠道、去线下找班长确认，而不是在群里 @ 发布者问"是真的吗"。相关套路详见[防骗指南](/notes/freshGuide/antiScam.html)。
- **家长不必加入学生群。** 班级通知你自己看得到，课程问题你自己问得了，社团活动你自己决定参不参加。

## 你的数字痕迹会跟着你很久

网络上发出去的内容，可以被截图、被转发、被搜索引擎收录、被人长期保存。删除原贴并不等于内容消失。任何时候都需要谨言慎行。

因此有两件事值得现在就做：一是趁着社交圈还没扩展开，清理一下过往不愿被人看到的公开内容；二是从现在起，把"这条内容如果被未来的同学、老师、导师或面试官看到，我是否介意"当成一个下意识的检查动作。

另外请记住一条硬性原则：**永远不要在可联网的设备或网盘上存放任何你不希望被别人看到的私密内容。** 手机丢失、账号被盗、云相册误同步，代价都由你自己承担。

## 开学前的账号准备清单

- [ ] 一个登记在自己名下、准备长期使用的手机号
- [ ] 一个中性、体面、长期可用的个人邮箱（例如：zhangsan@163.com LZ0915@tlook.com xxxxxx@qq.com）
- [ ] QQ 与微信各一个账号，均已实名并绑定手机与邮箱
- [ ] 清晰可辨的头像与昵称，个性签名中性得体
- [ ] 收紧空间与朋友圈可见范围
- [ ] 公开资料中不含宿舍、身份证、完整生日、家庭住址
- [ ] 主要账号密码互不相同，已开启二次验证与设备锁
- [ ] 已清理过往不愿被现在的同学看到的公开内容

> 建立账号只需要十分钟，但它是你在大学里第一个完全由自己掌握、也完全由自己负责的东西。从这里开始，你的社交关系、你收到的信息、你留下的痕迹，都由你自己决定。
