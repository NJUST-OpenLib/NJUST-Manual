起初，我对"高中—大学衔接"这一概念颇不以为然。吃饭、睡觉、上课、购物、交友、出行、冲突处理——这些难道不是自然而然就会的事吗？一个即将步入成年的人，何需他人手把手地教导？

然而，这种想法本身就是一种"过来人"的傲慢。当一个人站在大学的终点回望，将四年乃至更长时间积累的经验视作理所当然，并要求高中毕业生即刻具备同等认知时，这种要求本身就不近人情。

我必须坦率地指出：我们的应试教育与部分家庭教育，在这一问题上负有不可推卸的责任。

对于许多高中生——尤其是"山河四省"等高考大省的学子而言，高中三年往往被简化为两件事：服从与学习。学校鲜少教授如何健康饮食、如何甄别商品优劣、如何维系适度的人际边界、如何识别形形色色的骗局。而部分家长则秉持着"你只需要学习，其他不用操心"的逻辑，对学生使用手机、电脑如临大敌，每逢周末便追问"为何不去学习"。

于是，当这些学生终于踏入大学，突然面对一个需要自主决策的世界时，茫然与失措便接踵而至。

## 关于提前规划的辩证思考

不可否认，暑假期间提前准备确有裨益：考取驾照、备战四六级、预习高等数学与线性代数、学习编程、了解考研考公路径、参与企业实习或社会实践……这些选择本身并无不妥。

我们也能看到，很多家长在暑假为孩子安排了各式各样的事情：学车、衔接班、背单词、学编程、社会实践……出发点是好的，但更值得留意的是这些事**如何**被安排。如果计划完全由家长单向制定、孩子只需照做，那么这与高中并无本质不同——只是把服从换了一种形式，假期结束后，孩子依旧没有学会为自己做出决定。

但我更想强调的是：比具体技能更重要的，是心态的转换。

与其质问子女"为何没有按计划学习"，家长们不妨先反躬自省：

- **您是否教授过孩子基本的生活技能？** 每年开学季，我们总能看到这样的场景：不会使用洗衣机，不会挑选新鲜蔬果，不会辨别产品优劣，不知道价格高低，更不懂得如何在消费中维护自身权益。
- **您是否引导过孩子建立健康的人际交往能力？** 在某些家庭中，高中生甚至没有一部属于自己的手机，更遑论与朋友结伴出行、独立处理人际关系，乃至理解亲密关系的边界与责任。
- **您的经验是否经过验证？您是否培养过孩子的批判性思维？** 许多新生尚不具备辨别网络信息真伪的能力。任何人混入群聊便可发布一条消息："最新通知，请所有人加入新生信息群××××，这是官方新群"——便有大量学生不加核实便扫码加入，最终上当受骗。

更令人忧虑的是，长期接受"服从式"教育的学生，面对涉及金钱的信息也缺乏核实意识。当看到群里出现"最新通知：请交资料费138元，逾期无法报考"时，他们的第一反应不是在官方渠道核实，而是在群里@发布者询问"是真的吗"，得到肯定答复后便直接转账。

这种"清澈"的单纯背后，是独立思考能力的缺失。

指责无益。我只想说：如果您无法提供有价值的建议，又习惯于指手画脚，那么适当的放手或许是最好的选择。请接受一个事实——他/她是一个独立的个体，有权也应当为自己的生活做出决策。

正因如此，我决定写下这本指南。我想传授的并非什么高深学问，而是那些被忽视的"常识"。
